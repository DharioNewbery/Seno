### Seno

### Features:
Criação de turmas pelo professor. Solicitação de entrada pelos alunos.
Criação de tarefas. Submissão e correção automática de algoritmos em ambiente isolado

3. Cadastro de alunos.
4. Criação de turmas.
5. Criação de tarefas de programação. submissão de tarefas.
6. Execução e correção automática de scripts.
7. Editor online com salvamento em tempo real para backup.
